# The FED-HUB Field Guide

> A practical philosophy for creative machines.

## Opening note

The first instinct is to ask a machine for an answer. The more interesting move is to ask it for a new angle on the question itself.

FED-HUB is not a vending machine for certainty. It is a studio light. Point it at the edge of an idea and notice what becomes visible.

## 1. Begin with a better question

A useful prompt does not describe a task perfectly. It opens a door.

Try moving from:

> Give me five taglines for my product.

To:

> What is the emotional promise hiding underneath this product, and what would it sound like if it were written by someone who had just discovered it?

The second prompt has room for interpretation. That room is where your taste begins working.

## 2. Invite the weird draft

Ask for the version that is too specific, too poetic, or too early to be useful. Weird drafts are not final answers. They are raw material with a pulse.

A good creative machine should occasionally make you say: “I would never have phrased it that way.” Keep those moments.

## 3. Keep the human edit

Your taste is not a bottleneck. It is the point of the loop.

AI can make possibility abundant. Abundance makes selection more important. The edit is where experience, context, memory, humor, and responsibility enter the room.

## A seven-minute practice

1. Bring one ordinary object to the conversation.
2. Ask FED-HUB to describe it as a weather system.
3. Ask it to describe the same object as a memory.
4. Ask it to describe the object as a small god.
5. Keep the metaphor that changes how you see the object.

## Closing

Treat intelligence as a material, not a destination.
